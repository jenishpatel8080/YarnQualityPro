# Yarn Inspection App

A React application for yarn quality inspection, built with Vite, TypeScript, and Tailwind CSS.

## Features

- Comprehensive yarn inspection workflow
- Photo evidence collection
- Lab data management
- Packaging checks
- Visual defect tracking
- Signature capture
- Report generation

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser to `http://localhost:5173`

## Build for Production

```bash
npm run build
```

## Technologies Used

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React (icons)
